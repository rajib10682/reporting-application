File Format Requirements

Upload .txt files with tilde-delimited format:

scenarioname~goc~account~currency~year~jan_amt~feb_amt~mar_amt~apr_amt~may_amt~jun_amt~jul_amt~aug_amt~sep_amt~oct_amt~nov_amt~dec_amt
Validation Rules
  • Scenario, GOC, Account, and Currency must be valid
  • Account must be a leaf account (no children)
  • Currency rates will be applied during ingestion
  • All monetary amounts will be transformed using FX rates
